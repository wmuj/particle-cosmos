# ✨ 粒子宇宙 PARTICLE COSMOS

> 十几万颗发光粒子听你号令。打一句话,让它替你点亮成星辰。

纯 WebGL 手写粒子引擎(零依赖、零构建、单页静态),桌面 13 万粒子 / 手机 4.5 万,自适应帧率降载保流畅。

## 玩法

- **星云**:倾斜旋转的三旋臂星系,核球发光、外围星尘晕
- **黑洞**:带黑色视界的吸积盘,粒子螺旋坠入、越近越亮越快
- **烟花**:环形绽放 + 双发齐放,星空底噪
- **文字**:输入任意 ≤12 字(中英文都行),粒子瞬间聚成发光大字 —— 传播杀手锏
- 全模式通用:鼠标/手指搅动星尘,点击/点按引爆冲击波(带音效)
- 4 套调色板(星辰/熔金/霓虹/极光),一键截图带水印,UI 闲置 4.5 秒自动隐身

## 本地运行

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 部署(免费)

整个文件夹是纯静态站,拖上去就能用:

- **Cloudflare Pages**(推荐,国内访问相对快)
- **Vercel**:`npx vercel`
- **GitHub Pages**:仓库 Settings → Pages
- 上线后给 `index.html` 补一个 `og:image`(用站内截图),分享卡片更好看

## 文件结构

```
index.html      入口 + UI 结构
css/style.css   玻璃拟态 UI,移动端自适应
js/main.js      全部引擎:WebGL 渲染 / 四模式物理 / 音效合成 / 截图 / FPS 自适应
```

关键可调参数都在 `js/main.js` 顶部与各 `upd*` 函数内:粒子数 `N`、拖影强度 `FADE`、调色板 `PALETTES`。
`window.COSMOS` 是调试钩子(step/ignite/setMode/info)。

## 传播玩法建议

1. **录屏**:黑洞模式 + 熔金调色板转 10 秒,再打一句话聚成文字 —— 一条完整的短视频
2. **句子挑战**:「把你最想说的一句话打进去」,观众截图晒图有天然动机
3. **节日限定**:跨年打「2027」、七夕打名字,配烟花模式,场景感拉满
4. **手机端直接转发链接**,零门槛即开即玩
